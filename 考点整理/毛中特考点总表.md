## 导论：马克思主义中国化时代化

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 命题提出 | 1938 年六届六中全会毛泽东作《论新阶段》，首次提出“马克思主义中国化” | 不是 1945 年七大才提出 |
| ★ 内涵 | 把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合（**两个结合**） | “两个结合”是新时代重要论述；第一个结合是根本途径，第二个结合是文化根基 |
| ★ 理论成果 | 毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观、习近平新时代中国特色社会主义思想 | 一脉相承又与时俱进；不是简单的“替代关系” |
| ★ 历史性飞跃 | 第三个历史决议规范表述为**三次历史性飞跃**：毛泽东思想；中国特色社会主义理论体系；习近平新时代中国特色社会主义思想（部分教材按四次划分，以本校教材/新大纲为准） | 选择题常考“第一次飞跃是毛泽东思想” |
| ★ 马克思主义中国化时代化 | 坚持马克思主义、发展马克思主义；坚持“两个结合”；不断回答中国之问、世界之问、人民之问、时代之问 | 不是“照搬马克思主义”或“背离马克思主义” |

**易错**：六届六中全会首次提出“马克思主义中国化”；“两个结合”是重大理论创新；理论成果是“一脉相承又与时俱进”。

## 第一章 毛泽东思想及其历史地位

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 形成条件 | 近代中国社会矛盾、革命实践；马克思主义传播；中国优秀传统文化 | 实践基础是中国共产党领导人民革命和建设 |
| ★ 形成过程 | 萌芽（大革命时期）→ 形成（土地革命战争时期）→ 成熟（遵义会议—中共七大）→ 发展（解放战争—新中国成立后） | 成熟标志是中共七大确立为指导思想 |
| ★ 主要内容 | 新民主主义革命理论；社会主义革命和社会主义建设理论；革命军队建设和军事战略；政策和策略；思想政治工作和文化工作；党的建设 | 六个方面，不要只记“革命理论” |
| ★ 活的灵魂 | **实事求是、群众路线、独立自主** | 实事求是是精髓；群众路线是根本工作路线 |
| ★ 历史地位 | 马克思主义中国化第一次历史性飞跃；中国革命和建设的科学指南；中国共产党和中国人民宝贵精神财富 | 毛泽东思想 ≠ 毛泽东个人思想 |
| ★ 科学评价毛泽东 | 功绩是第一位的，错误是第二位的；区分毛泽东思想与毛泽东晚年错误 | 不能因为晚年错误否定毛泽东思想 |

**易错**：毛泽东思想是集体智慧的结晶；实事求是、群众路线、独立自主是活的灵魂；毛泽东思想写入党章是 1945 年中共七大。

**分析题角度**：毛泽东思想为什么是马克思主义中国化第一次飞跃；如何科学评价毛泽东和毛泽东思想。

## 第二章 新民主主义革命理论

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 总路线 | 无产阶级领导的、人民大众的、反对帝国主义、封建主义、官僚资本主义的革命 | 领导权是核心；对象、动力、领导、性质、前途 |
| ★ 革命对象 | 帝国主义、封建主义、官僚资本主义 | 帝国主义是首要对象；官僚资本主义是革命对象 |
| ★ 革命动力 | 工人、农民、城市小资产阶级、民族资产阶级 | 农民是主力军；民族资产阶级具有两面性 |
| ★ 领导权 | 无产阶级领导权是新民主主义革命的核心问题 | 通过共产党实现；不能“二次革命论” |
| ★ 性质与前途 | 性质是资产阶级民主革命；前途是社会主义 | 不是旧民主主义革命；不是社会主义革命 |
| ★ 基本纲领（政治） | 建立无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义共和国；民主集中制；人民代表大会 | 不是资产阶级共和国 |
| ★ 基本纲领（经济） | 没收官僚资本归国家所有；没收地主土地分配给农民；保护民族工商业 | “节制资本”“平均地权” |
| ★ 基本纲领（文化） | 民族的、科学的、大众的文化 | 不是“全盘西化” |
| ★ 三大法宝 | **统一战线、武装斗争、党的建设** | 三大法宝相互关系 |
| ★ 农村包围城市道路 | 农村包围城市、武装夺取政权；工农武装割据 | 马克思主义中国化重要成果 |
| ★ 意义 | 指导中国革命胜利；丰富马克思主义；体现马克思主义中国化 | 不是“照搬俄国道路” |

**易错**：新民主主义革命性质是资产阶级民主革命，但领导权是无产阶级；民族资产阶级是动力之一但不是领导力量；三大法宝不是“统一战线、土地革命、党的建设”。

**分析题角度**：新民主主义革命理论的内容和意义；为什么说领导权问题是核心。

## 第三章 社会主义改造理论

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 过渡时期总路线 | 一化三改：社会主义工业化 + 对农业、手工业、资本主义工商业的社会主义改造 | 一化是主体，三改是两翼 |
| ★ 农业改造 | 互助组 → 初级农业生产合作社 → 高级农业生产合作社 | 自愿互利、典型示范、国家帮助 |
| ★ 手工业改造 | 供销小组 → 供销合作社 → 生产合作社 | 逐步过渡 |
| ★ 资本主义工商业改造 | 和平赎买；初级形式国家资本主义 → 个别企业公私合营 → 全行业公私合营 | 和平赎买是创举 |
| ★ 历史经验 | 社会主义工业化与改造并举；逐步过渡；和平改造；把资本家改造成自食其力劳动者 | 后期存在要求过急等偏差 |
| ★ 制度确立 | 1956 年底三大改造基本完成，社会主义制度基本建立 | 标志中国进入社会主义初级阶段 |
| ★ 意义 | 最深刻最伟大的社会变革；为工业化奠定基础；丰富科学社会主义 | 不是“消灭资本主义”的简单过程 |

**易错**：过渡时期总路线主体是工业化；资本主义工商业改造不是没收；1956 年才标志社会主义制度基本建立。

**分析题角度**：为什么说社会主义改造是中国历史上最深刻最伟大的社会变革；和平赎买的意义。

## 第四章 社会主义建设道路初步探索的理论成果

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★《论十大关系》 | 1956；以苏为鉴；调动一切积极因素为社会主义事业服务 | 标志党开始探索中国自己的建设道路 |
| ★ 中共八大 | 1956；主要矛盾、主要任务：集中力量发展生产力 | 八大路线正确但未坚持 |
| ★ 两类矛盾 | 1957《关于正确处理人民内部矛盾的问题》；敌我矛盾、人民内部矛盾 | 人民内部矛盾用民主方法解决 |
| ★ 探索意义 | 巩固社会主义制度；发展社会主义经济；丰富科学社会主义理论 | 初步探索有曲折 |
| ★ 经验教训 | 必须从国情出发、遵循经济规律、加强民主法制、坚持党的领导 | 失误是探索中的失误 |

**易错**：八大主要矛盾不是“阶级斗争”；人民内部矛盾不能用专政方法；《论十大关系》不是“改革开放”文件。

**分析题角度**：如何评价社会主义建设道路初步探索；八大路线为什么没有坚持。

## 第五章 邓小平理论

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 首要基本理论问题 | 什么是社会主义、怎样建设社会主义 | 邓小平理论的核心 |
| ★ 社会主义本质 | 解放生产力、发展生产力，消灭剥削、消除两极分化，最终达到共同富裕 | 本质论；不是“平均主义” |
| ★ 社会主义初级阶段 | 我国已经进入社会主义初级阶段，并将长期处于初级阶段 | 不是“任何国家都要经历” |
| ★ 基本路线 | 一个中心、两个基本点：以经济建设为中心，坚持四项基本原则，坚持改革开放 | 十三大系统阐述 |
| ★ 改革开放 | 改革是中国的第二次革命；开放也是改革 | 改革不是“改旗易帜” |
| ★ 社会主义市场经济 | 计划和市场都是经济手段；社会主义也可以搞市场经济 | 十四大确立改革目标 |
| ★ 两手抓 | 一手抓改革开放，一手抓打击犯罪；一手抓物质文明，一手抓精神文明 | 两手都要硬 |
| ★ 一国两制 | 一个国家、两种制度；港澳回归 | 香港 1997、澳门 1999 |
| ★ 历史地位 | 马克思主义中国化第二次历史性飞跃；中国特色社会主义理论体系开篇 | 十五大写入党章 |

**易错**：社会主义本质不是“公有制+按劳分配”；市场经济不是资本主义专利；邓小平理论写入党章是十五大。

**分析题角度**：邓小平理论的历史地位；为什么说改革是中国的第二次革命。

## 第六章 “三个代表”重要思想

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 形成条件 | 党的建设面临新形势；世情国情党情变化 | 回答“建设什么样的党、怎样建设党” |
| ★ 核心观点 | 始终代表中国先进生产力的发展要求；代表中国先进文化的前进方向；代表中国最广大人民的根本利益 | 三者统一于党的建设 |
| ★ 历史地位 | 立党之本、执政之基、力量之源；马克思主义中国化新发展 | 十六大写入党章 |
| ★ 本质 | 立党为公、执政为民 | 不是“三民主义” |

**易错**：三个代表不是“三个有利于”；写入党章是十六大。

**分析题角度**：三个代表重要思想的历史地位；如何理解立党为公、执政为民。

## 第七章 科学发展观

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|

**分析题角度**：科学发展观的内涵和历史地位。

## 第八章 习近平新时代中国特色社会主义思想及其历史地位

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 形成条件 | 新时代国内外形势变化和实践发展；回答“新时代坚持和发展什么样的中国特色社会主义、怎样坚持和发展中国特色社会主义”等重大时代课题 | 新时代 |
| ★ 核心内容 | **十个明确、十四个坚持、十三个方面成就** | 十个明确是核心内容 |
| ★ 世界观方法论 | **六个必须坚持**：人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下 | 立场观点方法 |
| ★ 历史地位 | 当代中国马克思主义、二十一世纪马克思主义；中华文化和中国精神的时代精华；马克思主义中国化新的飞跃 | 十九大写入党章 |
| ★ “两个结合” | 同中国具体实际相结合、同中华优秀传统文化相结合 | 第二个结合是重大理论创新；连接毛泽东思想与新时代 |
| ★ 两个确立 | 确立习近平同志党中央的核心、全党的核心地位；确立习近平新时代中国特色社会主义思想的指导地位 | 决定性意义 |
| ★ 两个维护 | 坚决维护习近平总书记党中央的核心、全党的核心地位；坚决维护党中央权威和集中统一领导 | 最高政治原则 |

**易错**：十个明确、十四个坚持、十三个方面成就不要混；六个必须坚持是世界观方法论；两个确立/两个维护不同。

**分析题角度**：习近平新时代中国特色社会主义思想的历史地位；如何理解“两个确立”的决定性意义。

## 第九章 坚持和发展中国特色社会主义的总任务

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 中国梦 | 国家富强、民族振兴、人民幸福；实现中华民族伟大复兴 | 中国梦的本质 |
| ★ 两步走 | 2020 全面建成小康社会；2035 基本实现社会主义现代化；本世纪中叶建成富强民主文明和谐美丽的社会主义现代化强国 | 时间节点 |
| ★ 中国式现代化 | 人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路 | 五个特征回答“是什么样子” |
| ★ 五个特征 vs 九个本质要求 | 五个特征是“中国特色/是什么样”；九个本质要求回答“由什么决定、本质属性” | 选择题常交叉设错：不要把本质要求当特征 |
| ★ 中国式现代化本质要求 | 坚持中国共产党领导，坚持中国特色社会主义，实现高质量发展，发展全过程人民民主，丰富人民精神世界，实现全体人民共同富裕，促进人与自然和谐共生，推动构建人类命运共同体，创造人类文明新形态 | 九个方面，顺序可记“领导—道路—发展—民主—精神—富裕—生态—世界—文明” |
| ★ 中国式现代化本质要求 | 坚持中国共产党领导，坚持中国特色社会主义，实现高质量发展，发展全过程人民民主，丰富人民精神世界，实现全体人民共同富裕，促进人与自然和谐共生，推动构建人类命运共同体，创造人类文明新形态 | 九个方面 |
| ★ 重大原则 | 坚持和加强党的全面领导；坚持中国特色社会主义道路；坚持以人民为中心的发展思想；坚持深化改革开放；坚持发扬斗争精神 | 五个重大原则 |

**易错**：2035 基本实现现代化，本世纪中叶建成强国；中国式现代化不是西方化。

**分析题角度**：中国式现代化的中国特色和本质要求；如何实现中华民族伟大复兴。

## 第十章 “五位一体”总体布局

### 经济

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 新发展理念 | 创新、协调、绿色、开放、共享 | 指挥棒、红绿灯 |

### 政治

| ★ 全过程人民民主制度载体 | 人民代表大会制度（根本）、中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度 | 根本政治制度与基本政治制度要区分 |

| ★ 全面依法治国 | 总目标：建设中国特色社会主义法治体系、建设社会主义法治国家 | 依宪治国、依宪执政 |

## 第十四章 坚持和加强党的领导

| 考点 | 必背核心 | 考法/易错 |
|---|---|---|
| ★ 党的领导地位 | 中国共产党领导是中国特色社会主义最本质的特征，是中国特色社会主义制度的最大优势 | 最高政治领导力量 |
| ★ 两个维护 | 维护习近平总书记核心地位、维护党中央权威和集中统一领导 | 最高政治原则 |
| ★ 全面从严治党 | 核心是加强党的领导；自我革命是跳出历史周期率的第二个答案 | 第一个答案是人民监督 |
