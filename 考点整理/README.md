## 怎么用

**第一轮（搭框架）**
1. 先看每章开头的“章节定位”和总览表，知道这章在历史/理论主线中的位置；
2. 再背表格里的“必背核心”，每章挑 5–8 条最重要的；
3. 对照时间轴，把事件和章节对应起来（史纲尤其重要）。

**第二轮（刷选择题）**
1. 重点看“考法/易错”列，把易混点抄成一句话；
2. 用《高频易错 30 条》做自测，能说出每条为什么错；
3. 史纲注意时间、文件、会议、性质、意义五类关键词。

**第三轮（分析题）**
1. 按“背景—内容—性质—意义—教训”搭框架；
2. 毛中特按“理论定位—核心内容—形成背景—理论/实践意义—方法论”搭框架；
3. 不要求逐字背，但关键词必须准确。
