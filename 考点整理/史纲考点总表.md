# 史纲考点总表（2027 南开 070200 物理考研政治）

> 依据：2026 考研政治大纲「中国近现代史纲要」11 章框架；适配 2027 入学（2026 年 12 月考试）。
> 用法：先背“必背核心”里的关键词，再对照“时间轴”记事件顺序，最后看“考法/易错”。标 ★ 为选择题高频，标 ◆ 为分析题高频。

## 0. 总览：五条主线

| 主线 | 关键词 | 对应章节 |
|---|---|---|
| 侵略与反抗 | 半殖民地半封建、两大历史任务、民族觉醒 | 第 1 章 |
| 早期探索 | 太平天国、洋务运动、戊戌维新 | 第 2 章 |
| 辛亥革命 | 三民主义、临时约法、推翻君主专制 | 第 3 章 |
| 新民主主义革命 | 五四、中共成立、农村包围城市、抗战、解放 | 第 4–7 章 |
| 社会主义与新时代 | 三大改造、改革开放、新时代、中国式现代化 | 第 8–11 章 |

**一条总线索**：近代以来，中国逐步沦为半殖民地半封建社会 → 各阶级探索救国道路 → 中国共产党领导新民主主义革命胜利 → 社会主义制度确立 → 改革开放 → 中国特色社会主义新时代。

## 上编：旧民主主义革命时期（1840–1919）

### 第一章 进入近代后中华民族的磨难与抗争

**章节定位**：近代史开端、社会性质变化、两大历史任务、列强侵略与民族觉醒。

| 考点 | 必背核心 | 时间轴 | 考法/易错 |
|---|---|---|---|
| ★ 近代中国社会性质 | 鸦片战争后由封建社会逐步变为**半殖民地半封建社会** | 1840 后 | 半殖民地是“形式独立、实际受控”；半封建是“封建经济解体、资本主义有发展但未占主导” |
| ★ 半殖民地 vs 半封建 | **半殖民地侧重国家地位/主权**；**半封建侧重社会经济结构** | 1840 后 | 选择题常把二者混成“一半殖民地一半封建”，要分开表述 |
| ★ 近代中国主要矛盾 | **帝国主义与中华民族**、**封建主义与人民大众** | 1840–1949 | 两大矛盾相互交织；不同时期主次有变化 |
| ★ 两大历史任务 | **民族独立、人民解放**；**国家富强、人民幸福** | 1840 后 | 前者是前提，后者是目的；不能颠倒 |
| ★ 鸦片战争 | 1840–1842；英国发动；《南京条约》 | 1840 | 中国近代史开端；不是“中国开始落后”的起点 |
| ★《南京条约》 | 割香港岛、赔款 2100 万银元、五口通商、协定关税 | 1842 | 第一个不平等条约；协定关税破坏关税自主 |
| ★ 列强侵华方式 | 军事侵略、政治控制、经济掠夺、文化渗透 | 1840–1901 | 经济上从商品输出为主到资本输出为主（甲午后） |
| ★ 不平等条约体系 | 领事裁判权、片面最惠国待遇、租界、协定关税、势力范围 | 1842–1901 | 领事裁判权破坏司法主权；租界是“国中之国” |
| ★ 甲午中日战争 | 1894–1895；黄海海战、威海卫之战；《马关条约》 | 1894 | 割台湾及澎湖列岛、赔款 2 亿两、允许设厂；半殖民地化大大加深 |
| ★ 瓜分中国狂潮 | 租借地、势力范围；门户开放 | 1898 | 列强强租港湾不等于“割让”；美国“门户开放”是分赃政策 |
| ★ 边疆危机 | 西北：阿古柏入侵、俄占伊犁；东南：日本侵台、琉球；西南：马嘉理事件、中法战争 | 1864–1885 | 边疆危机是列强从周边蚕食中国；左宗棠收复新疆是成功案例 |
| ★ 左宗棠收复新疆 | “先北后南、缓进急战”；1876 收复新疆大部；1884 新疆建省 | 1876–1884 | 不是“放弃新疆”；新疆建省加强西北管理 |
| ★ 中法战争 | 1883–1885；马尾海战、镇南关大捷；《中法新约》 | 1883–1885 | 中国“不败而败”；法国势力深入西南 |
| ★ 台湾建省 | 1885 中法战争后建省；刘铭传首任巡抚 | 1885 | 加强东南海防；不是“割让” |
| ★ 八国联军与《辛丑条约》 | 1900–1901；赔款 4.5 亿两、驻兵、禁止人民反帝 | 1900 | 中国完全沦为半殖民地半封建社会；清政府成为“洋人的朝廷” |
| ★ 反侵略斗争 | 三元里抗英、台湾人民反割台、义和团运动 | 1841/1895/1900 | 义和团“扶清灭洋”：反帝爱国但盲目排外；粉碎列强瓜分图谋 |
| ★ 民族意识觉醒 | 林则徐睁眼看世界；魏源“师夷长技以制夷”；郑观应“商战”；严复《天演论》；孙中山“振兴中华” | 1840–1895 | 从器物到制度到思想；《海国图志》不是《天演论》 |
| ★ 反侵略失败原因 | 社会制度腐败、经济技术落后；民族觉醒不足 | 1840–1901 | 根本原因是制度腐败，不是武器不如人 |

**本章易错**
1. 鸦片战争是中国近代史开端，不是中国近代化开端；近代化开端是洋务运动。
2. 半殖民地半封建社会不是“一半殖民地一半封建”。
3. 两大历史任务不能互换；民族独立人民解放是前提。
4. 《马关条约》允许日本在通商口岸设厂，标志列强侵华进入资本输出阶段。
5. 《辛丑条约》没有割地，但中国完全沦为半殖民地半封建社会。

**分析题角度**：为什么说鸦片战争是中国近代史的转折点；近代中国两大历史任务及其关系；从列强侵略看“落后就要挨打”。

### 第二章 不同社会力量对国家出路的早期探索

**章节定位**：农民阶级、地主阶级洋务派、资产阶级维新派三次探索；证明旧道路走不通。

| 考点 | 必背核心 | 时间轴 | 考法/易错 |
|---|---|---|---|
| ★ 太平天国运动 | 1851 金田起义；1853 定都天京；《天朝田亩制度》《资政新篇》 | 1851–1864 | 旧式农民战争最高峰；沉重打击清朝和外国侵略势力 |
| ★《天朝田亩制度》 | 平均土地、绝对平均主义；反映农民愿望但无法实现 | 1853 | 空想性；不是资本主义方案 |
| ★《资政新篇》 | 洪仁玕提出；学习西方、发展资本主义；未实施 | 1859 | 中国近代第一个比较系统的资本主义改革方案 |
| ★ 太平天国失败 | 农民阶级局限性、缺乏科学理论、领导集团内讧、中外反动势力联合镇压 | 1864 | 根本原因是农民阶级局限性 |
| ★ 洋务运动 | 19 世纪 60–90 年代；“自强”“求富”；军事工业、民用工业、新式海军、新式学堂 | 1861–1895 | 地主阶级洋务派自救运动；中国近代化开端 |
| ★ 洋务运动失败 | **封建性、依赖性、腐朽性**；只学技术、不改制度；甲午战败标志破产 | 1895 | 三性：封建性（维护封建统治）、依赖性（依赖外国）、腐朽性（衙门式管理） |
| ★ 洋务运动作用 | 开启近代化、刺激民族资本主义、培养人才、抵制外来侵略 | 1861–1895 | 不改变封建生产关系，不能使中国富强 |
| ★ 洋务企业 | 军事：江南制造总局、福州船政局；民用：轮船招商局、汉阳铁厂 | 1865–1890 | 从“自强”到“求富”；封建管理方式束缚发展 |
| ★ 北洋海军 | 1888 成军；甲午一战全军覆没 | 1888–1895 | 洋务运动军事成就；只学技术不能救国 |
| ★ 戊戌维新 | 1898；康有为、梁启超、谭嗣同；百日维新 | 1898 | 资产阶级改良运动；思想启蒙 |
| ★ 维新派与守旧派论战 | 要不要变法、要不要兴民权、要不要废八股 | 1898 | 实质是资产阶级思想与封建主义思想之争 |
| ★ 戊戌变法失败 | 资产阶级软弱性、依靠没有实权的皇帝、脱离群众、守旧势力强大 | 1898 | 证明资产阶级改良道路走不通 |
| ★ 戊戌变法意义 | 爱国救亡、思想启蒙、推动近代教育/新闻/政治改革 | 1898 | 不是“成功了”，而是失败但影响深远 |
| ★ 三次探索比较 | 农民阶级、地主阶级洋务派、资产阶级维新派 | 1851–1898 | 都不能改变半殖民地半封建性质；阶级局限性决定失败 |

**本章易错**
1. 太平天国是旧式农民战争，不是资产阶级革命。
2. 《资政新篇》不是太平天国后期实际实施的政策。
3. 洋务运动是地主阶级自救，不是资产阶级改革。
4. 戊戌变法失败说明改良道路走不通，不是“君主立宪完全不可能”。
5. 近代化开端是洋务运动，不是鸦片战争。

**分析题角度**：太平天国/洋务运动/戊戌维新为什么失败；从三次探索看“三个选择”的历史必然性。

### 第三章 辛亥革命与君主专制制度的终结

| 考点 | 必背核心 | 时间轴 | 考法/易错 |
|---|---|---|---|
| ★ 清末新政 | 1901 后；废科举、编练新军、奖励实业、预备立宪 | 1901–1911 | 清政府自救，客观上促进资本主义发展，但未挽救统治 |
| ★ 三民主义 | 民族主义（驱除鞑虏、恢复中华）、民权主义（建立民国）、民生主义（平均地权） | 1905 | 旧三民主义没有明确反帝、没有彻底土地纲领 |
| ★ 同盟会 | 1905 东京；第一个全国性资产阶级革命政党 | 1905 | 不是“第一个革命团体”（兴中会 1894） |
| ★ 革命派与改良派论战 | 要不要以革命推翻清王朝、要不要实行共和、要不要平均地权 | 1905–1907 | 实质是资产阶级革命派与改良派之争 |
| ★ 武昌起义 | 1911 年 10 月 10 日；湖北新军 | 1911 | 辛亥革命首义；不是孙中山直接领导 |
| ★ 中华民国成立 | 1912 年 1 月 1 日；南京；孙中山临时大总统 | 1912 | 共和制度确立 |
| ★《中华民国临时约法》 | 主权在民、三权分立、责任内阁；中国第一部资产阶级共和国宪法性质文件 | 1912 | 不是社会主义宪法；未真正实施 |
| ★ 辛亥革命意义 | 推翻清王朝、结束君主专制制度、建立共和、思想解放 | 1911 | 没有改变半殖民地半封建性质；没有完成反帝反封建任务 |
| ★ 袁世凯窃取果实 | 帝国主义支持袁世凯；革命党人妥协；立宪派、旧官僚施压；孙中山让位 | 1912 | 因果链：帝国主义+旧势力+革命派软弱 → 袁世凯窃取 |
| ★ 辛亥革命失败 | 资产阶级软弱性和妥协性；没有发动群众；没有彻底反帝反封建 | 1912 | 根本原因是阶级局限性；没有改变半殖民地半封建性质 |
| ★ 北洋军阀 | 袁世凯窃取政权；军阀割据混战 | 1912–1928 | 北洋军阀是帝国主义支持下的封建军阀 |

**本章易错**
1. 辛亥革命推翻的是君主专制制度，不是封建制度。
2. 三民主义没有明确反帝；民生主义不是“耕者有其田”。
3. 临时约法具有资产阶级共和国宪法性质，但未真正实施。
4. 辛亥革命没有改变中国社会性质，也没有完成两大历史任务。

**分析题角度**：辛亥革命为什么失败；资产阶级共和国方案为什么在中国行不通。

## 中编：新民主主义革命时期（1919–1949）

### 第四章 中国共产党成立和中国革命新局面

| 考点 | 必背核心 | 时间轴 | 考法/易错 |
|---|---|---|---|
| ★ 新文化运动 | 1915 陈独秀《青年杂志》；民主与科学；鲁迅、胡适 | 1915 | 思想解放运动；为五四作思想准备 |
| ★ 五四运动 | 1919；巴黎和会外交失败；学生先锋、工人阶级登台 | 1919 | 新民主主义革命开端；彻底反帝反封建 |
| ★ 五四意义 | 促进马克思主义传播、工人阶级登上政治舞台、新民主主义革命开端 | 1919 | 不是社会主义革命；是新民主主义革命 |
| ★ 马克思主义传播 | 李大钊《我的马克思主义观》；各地共产主义小组 | 1919–1921 | 为中共成立作思想、组织、阶级准备 |
| ★ 中共成立 | 1921 一大；上海/嘉兴南湖；中共诞生 | 1921 | 开天辟地的大事变；中国革命面貌焕然一新 |
| ★ 中共二大 | 1922；第一次提出反帝反封建民主革命纲领 | 1922 | 最低纲领：打倒军阀、推翻帝国主义、统一中国为真正民主共和国 |
| ★ 中共三大 | 1923；确定共产党员以个人身份加入国民党，推动国共合作 | 1923 | 二大提出纲领 → 三大确定合作方针 → 1924 国民党一大合作实现 |
| ★ 国共合作 | 1924 国民党一大；第一次国共合作 | 1924 | 国民革命兴起；不是“两党合并” |
| ★ 大革命 | 1924–1927；北伐战争；工农运动高涨 | 1924–1927 | 基本推翻北洋军阀统治；领导权问题未解决 |
| ★ 大革命失败 | 1927 国民党右派叛变；陈独秀右倾错误 | 1927 | 教训：必须掌握革命武装、坚持无产阶级领导权 |

**本章易错**
1. 五四运动是新民主主义革命开端，不是旧民主主义革命。
2. 中共一大没有提出反帝反封建纲领，二大才提出。
3. 第一次国共合作采取“党内合作”形式。
4. 大革命失败不等于革命失败，而是进入土地革命新时期。

**分析题角度**：为什么五四运动是新民主主义革命开端；为什么中国共产党成立是开天辟地的大事变。

### 第五章 中国革命的新道路

| 考点 | 必背核心 | 时间轴 | 考法/易错 |
|---|---|---|---|
| ★ 八七会议 | 1927 汉口；确定土地革命和武装反抗国民党反动派总方针；毛泽东“枪杆子里出政权” | 1927 | 不是“确定农村包围城市道路”，而是总方针 |
| ★ 秋收起义 | 1927；毛泽东领导；文家市转兵、三湾改编 | 1927 | 三湾改编确立党对军队的领导 |
| ★ 井冈山道路 | 农村包围城市、武装夺取政权；工农武装割据 | 1927–1930 | 马克思主义中国化的重要开端 |
| ★ 工农武装割据 | 土地革命、武装斗争、根据地建设三者结合 | 1928–1934 | 土地革命是中心内容 |
| ★ 土地革命阶级路线 | 依靠贫雇农、联合中农、限制富农、消灭地主阶级；按人口平分土地 | 1928–1934 | 与抗战“减租减息”、解放战争“耕者有其田”对比记忆 |
| ★ 古田会议 | 1929；思想建党、政治建军 | 1929 | 确立思想建党政治建军原则 |
| ★ 中华苏维埃 | 1931 瑞金；中华苏维埃共和国临时中央政府 | 1931 | 农村革命根据地政权建设 |
| ★ 长征 | 1934–1936；第五次反围剿失败后战略转移 | 1934–1936 | 保存革命火种；长征精神 |
| ★ 遵义会议 | 1935；确立毛泽东领导地位；生死攸关转折点 | 1935 | 中国共产党独立自主解决中国革命问题的开端 |
| ★ 长征意义 | 粉碎围剿、保存骨干、播撒火种、铸就长征精神 | 1936 | 不是“北上抗日”单一原因 |

**本章易错**
1. 八七会议确定的是土地革命和武装反抗总方针，不是“农村包围城市”。
2. 井冈山是第一个农村革命根据地；“工农武装割据”中心内容是土地革命。
3. 遵义会议确立毛泽东在党中央和红军的领导地位，不是“确立毛泽东思想为指导思想”。
4. 长征结束标志：1936 年 10 月三大主力会师。

**分析题角度**：为什么必须走农村包围城市道路；遵义会议为什么是生死攸关的转折点。

### 第六章 中华民族的抗日战争

| 考点 | 必背核心 | 时间轴 | 考法/易错 |
|---|---|---|---|
| ★ 九一八事变 | 1931；局部抗战开始；东北沦陷 | 1931 | 中国抗战起点；不是全面抗战起点 |
| ★ 华北事变 | 1935；民族危机加深；一二·九运动 | 1935 | 中日民族矛盾上升为主要矛盾 |

## 下编：社会主义革命和建设时期（1949–1978）

### 第八章 中华人民共和国的成立和中国社会主义制度的确立

| 考点 | 必背核心 | 时间轴 | 考法/易错 |
|---|---|---|---|

| ★ 巩固政权 | 抗美援朝、土地改革、镇压反革命、“三反”“五反” | 1950–1952 | 为社会主义改造创造条件 |
| ★ 过渡时期总路线 | 一化三改：社会主义工业化 + 对农业、手工业、资本主义工商业改造 | 1953 | 主体是工业化；两翼是改造 |

| ★ 一届全国人大 | 1954；通过 1954 年宪法；人民代表大会制度确立 | 1954 | 根本政治制度；不是“政治协商制度” |

4. 1954 年宪法是第一部社会主义类型宪法，不是新中国第一部宪法？注意：它是第一部社会主义类型宪法。

**分析题角度**：为什么说社会主义改造是中国历史上最深刻最伟大的社会变革；和平赎买的意义。
